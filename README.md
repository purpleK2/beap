# beap
A basic linked list-based heap made initially for [purpleK2](https://github.com/purpleK2/rtos).

To implement this in your project, check [src/beap.h](src/beap.h) for details.

For an example of implementing the kernel-side functions, check [heap_wrappers.c](https://github.com/purpleK2/purpleK2/blob/dev-unstable/src/kernel/memory/heap/heap_wrappers.c) at purpleK2.
